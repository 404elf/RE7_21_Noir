# RE7 / 21 — NOIR

**中文** | [English](README.en.md)

基于《生化危机 7》「21」玩法的非官方独立桌面卡牌游戏。共用 1–11 数字牌堆，隐藏首牌，用王牌改变赌注与局势。保留原项目的卡牌规则，换上暗色牌桌、中文界面与更方便的玩法设置。

[**下载 Windows 版**](https://github.com/404elf/RE7_21_Noir/releases/latest) · [反馈问题](https://github.com/404elf/RE7_21_Noir/issues) · [更新记录](CHANGELOG.md)

![游戏牌桌](images/noir-table.png)

## 下载即玩

1. 在 Releases 下载 **RE7-21-Windows.zip**，完整解压。
2. 双击 **RE7_21_Noir.exe**，选择人机对战即可开始。不需要 Python 或额外组网软件。
3. 点击王牌查看效果；向牌桌拖动使用，向右拖动弃置。抽牌或停牌交给对手行动。

不要直接在压缩包里启动，也不要单独移动 exe。中文为默认，可在游戏中切换 English。

## 有什么可玩

- **人机对战**：多档难度；保守、赌徒、摇摆型风格，以及独立策略的极难挑战。AI 使用自己的手牌与公开线索判断。
- **朋友对战**：局域网搜索、地址直连、房间码和自建服务器收藏。异地房间码需要可用的房间服务器；目前没有官方公共服务器，也不提供自动 NAT 穿透。[联机说明](NETWORKING.md)
- **自由配牌**：预设、一键随机、逐项随机锁定；可从预设继续修改并另存。随机不会改动目标点数，默认仍为 21。
- **牌局节奏**：不限时、1+0 到 30+0 等预设及自定义；只有抽牌和停牌加秒。启用计时时，仅整场第一局双方各有 30 秒首次行动准备时间，准备超时判负。
- **方便复盘**：你 / 对手视角日志、亮牌结算、再来一局、投降与申请平局。点选的卡牌说明始终优先，动画和对手通知不阻止查看。

## 自定义在哪里

大部分修改直接在大厅的「游戏配置」「计时设置」完成，保存后用于下一场；音量立即生效。

| 下载包文件夹 | 内容 |
| --- | --- |
| `custom/game/` | 当前对局规则 `config.json` |
| `custom/presets/` | 玩法预设，可自行加入 JSON 文件 |
| `custom/timer/` | 时间额度、准备时间、亮牌等待 |
| `custom/audio/` | 音量、事件音效与 `sounds/` |
| `custom/network/` | 联机地址、服务端、更新设置 |
| `userdata/` | 本地战斗日志、配置备份、下载更新 |
| `docs/` | 使用说明、聊天 AI 配置指南、联机部署说明 |

想说一句需求就配好玩法？把 [**AI 配置说明**](docs/AI-CONFIG-GUIDE.md) 复制到聊天 AI，再描述你想玩的规则。将返回的 JSON 放进 `custom/presets/`，在预设页刷新、选择并保存即可。内附“烛火局”“最后一根手指”“地下室的盛宴”等玩法；先选一个，再按喜好调整。

自定义计时允许单项“不限时”；关闭计时也关闭准备倒计时。锁定只限制本次编辑中的一键随机，不妨碍你手动修改或主动切换预设，可一键解锁。默认 21 点由目标王牌在对局中改变，与随机配置是两回事。

## 项目说明

这是玩家制作的非官方项目，与 CAPCOM 无隶属关系。RE7 / Resident Evil 名称属于其权利人。程序可离线单机运行；联网仅用于你选择的对局或手动 GitHub 更新。

开发者运行方式：Python 3.12，安装 `requirements.txt` 后执行 `python main.py`。源码目录保持开发用布局；上述 `custom/` 分类是 Windows 下载包布局。测试与验证记录保留在源码中，不放进玩家包。
